# Sudais Khan Freelancer Portfolio

**Purpose:** Classroom project, *Activity 2 – Create a Basic Freelancer Portfolio*.
A one-page portfolio for Sudais Khan, Web Developer & UI/UX Designer.

## Technologies
HTML5, CSS3, vanilla JavaScript (no frameworks)

## Features
- Responsive design (mobile, tablet, desktop)
- Mobile hamburger navigation with smooth scrolling
- Skills section and Services section
- 3 sample projects: KICKSOUT, Creative Portfolio, SAVORIA
- Contact form with validation (demo only, no backend)

## Structure
```
sudais-khan-portfolio/
├── index.html
├── css/style.css
├── js/script.js
├── assets/images/
├── assets/icons/
└── README.md
```

## Run locally
1. Download the project
2. Open `index.html` in a browser

## Deploy with GitHub Pages
1. Create a GitHub repository named `sudais-khan-portfolio`
2. Upload all files (keep the folder structure)
3. Go to **Settings**
4. Open **Pages**
5. Under *Build and deployment*, choose **Deploy from a branch**
6. Select the **main** branch
7. Select the **/ (root)** folder
8. Click **Save**
9. Wait 1–2 minutes for deployment
10. Open the generated URL: `https://yourusername.github.io/sudais-khan-portfolio/`

## Replace with your own details
In `index.html`, search for `your.email@example.com`, `github.com/yourusername` and `linkedin.com/in/yourusername`. Also replace the `#` links on the project buttons.
